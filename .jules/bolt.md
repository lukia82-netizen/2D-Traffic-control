## 2026-07-21 - Road Group Filter & Projection Optimizations in VehicleRenderer
**Learning:** High-frequency rendering loops (running at 60 FPS) are extremely sensitive to spatial search queries (O(E) distance checks) and small temporary object allocations (such as `[lng, lat]` coordinate arrays passed to map.project). By caching the static lane-to-group mapping in an O(1) Map (`laneGroupCache`) using OSM node identifiers during map initialization, we bypass expensive spatial lookups for nearly all rendering frames. Additionally, hoisting map bounds getters and passing native `{lng, lat}` compatible objects directly to the map projection removes redundant function calls and garbage collection overhead.
**Action:** Always pre-compute static graph relationships (like lane-to-road joins) during initialization/load phases, and avoid allocating temporary arrays or invoking map bounds getters inside loop bodies that iterate over hundreds of active simulation entities.
