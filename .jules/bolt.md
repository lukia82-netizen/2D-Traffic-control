## 2026-10-31 - Line Segment Viewport Culling & Coordinate Reuse in RoadRenderer
**Learning:** In MapLibre/PixiJS overlay renderers like `RoadRenderer.drawRoads()`, calling `map.project()` on every graph edge and junction node during camera movement causes thousands of unnecessary matrix projections. Testing if both edge endpoints lie on the same side outside the geographic bounding box (with 10% padding margin) safely culls off-screen edges. Furthermore, reusing the projected screen endpoints `r.from` and `r.to` for junction caps avoids duplicate projections for every intersection node.
**Action:** When rendering 2D graph edges and node caps on MapLibre overlays, cull line segments before projection and reuse the calculated screen coordinates across subsequent rendering passes.
