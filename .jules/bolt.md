## 2025-05-18 - Hoisting bounds extraction and removing per-frame allocations in 60 FPS vehicle render loop
**Learning:** In high-frequency 60 FPS MapLibre + PixiJS rendering loops (`VehicleRenderer`), repeated calls to `map.getBounds()` bounds getters (`getWest()`, `getEast()`, etc.) inside per-entity loops create thousands of redundant function calls per frame. Additionally, passing `[lng, lat]` arrays to `map.project()` allocates thousands of temporary coordinate arrays per frame causing GC pressure.
**Action:** Always hoist `map.getBounds()` coordinate boundary getters outside per-entity rendering loops, pass objects with `{ lat, lng }` directly to `map.project()` without array wrapping, and reuse class-member collection instances (like `renderedIds` Sets) across frames.
