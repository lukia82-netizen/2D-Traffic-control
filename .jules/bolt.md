## 2025-02-17 - [Optimizing Road-Group Filtering in VehicleRenderer]
**Learning:** Checking whether a vehicle should be hidden based on road-group configuration on every frame created a major O(E) spatial segment search overhead across all edges for each vehicle in the simulation. By utilizing the pre-computed map structure and associating lane IDs directly with road groups during map initialization (via the OSM node IDs mapping), we can bypass spatial searches on moving vehicles with a O(1) lookup map, resorting to the expensive O(E) search only as a fallback.
**Action:** Always map backend or domain structural identifiers (such as lane IDs or node pairings) to their visual metadata on map loading or startup to prevent per-frame geometric and projection calculations in render loops.
