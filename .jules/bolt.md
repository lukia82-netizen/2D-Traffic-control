## 2026-07-05 - Optimize vehicle rendering and road-group filtering
**Learning:** High-frequency rendering loops (60 FPS) are extremely sensitive to temporary object allocations and redundant API calls. MapLibre's `project()` method accepts `LngLatLike` objects, allowing us to pass `VehicleState` directly and avoid thousands of `[lng, lat]` array allocations per frame. Furthermore, replacing $O(E)$ spatial searches with $O(1)$ lookups using a pre-computed `laneGroupCache` significantly reduces CPU overhead for road-group filtering.
**Action:** Always hoist expensive API calls (like `map.getBounds()`) outside of entity loops. Prefer passing existing objects that satisfy library interfaces over creating new wrapper arrays or objects. Pre-calculate spatial or property-based mappings into caches during data initialization.
